# Пульт

Управление Windows с Android по домашней сети. Без облачного сервера и аккаунта в приложении.

- Выключение и перезагрузка с подтверждением, блокировка экрана.
- Один таймер до 24 часов; подтверждение действия, создание и отмена с телефона. На ПК — окно отсчёта, отмена из трея и история таймеров.
- Громкость и системная команда play/pause.
- Темы «Сигнал», «Тихий», «Орбита» в настройках.
- Виджет «Питание» и расширенный виджет с громкостью −/+.
- Агент с окном, треем и включаемым автозапуском.
- HTTPS, сверка сертификата, временный код привязки, отзыв доступа.
- Раздельные релизы и проверка обновлений Android/Windows.

Минимум: Android 12 (API 31), Windows 10/11 x64. Включение через WoL и управление курсором пока вне первой версии.

## Первый запуск

1. Скачайте Android APK и установщик `pult-agent-…-win-x64-setup.exe` из [Releases](https://github.com/cveloy102/pult/releases). Для тестирования можно собрать debug APK.
2. Установите агент. По умолчанию он запускается при входе в Windows и находится в `%LOCALAPPDATA%\Programs\Pult`. Архив остаётся доступным для переносного запуска.
3. ПК и телефон должны быть в одной домашней сети. Для входящих подключений Windows нужна частная сеть и разрешение для агента в брандмауэре: TCP 47591 и UDP 47592. Не открывайте эти порты в интернет.
4. На ПК нажмите «Подключить телефон». На Android: Настройки → Найти ПК или введите показанный IP.
5. Сверьте **полный отпечаток сертификата**, отметьте совпадение и введите одноразовый код с ПК.
6. Добавьте виджет через обычное меню виджетов Android. Его тема следует настройкам приложения.

При выключении приложения Windows могут ожидать сохранения документов: принудительное закрытие не используется. Таймер работает при запущенном агенте. Пропущенный во сне или при остановке агента срок отменяется.

## Сборка

Windows: .NET SDK 10.

```powershell
dotnet build agent/Pult.Agent/Pult.Agent.csproj -c Release
dotnet run --project agent/Pult.Tests/Pult.Tests.csproj
dotnet publish agent/Pult.Agent/Pult.Agent.csproj -c Release -r win-x64 --self-contained true -o artifacts/agent
```

Android: JDK 17+, Android SDK 37.0 и build-tools 36.0.0; Gradle wrapper находится в `android/`.

```powershell
cd android
.\gradlew.bat :app:assembleDebug :app:lintDebug
```

Debug APK: `android/app/build/outputs/apk/debug/app-debug.apk`. Для релизной сборки настройте постоянный ключ подписи; debug-версия не обновится APK с другой подписью.

Локальная подписанная версия: `scripts/build-android-release.ps1` (Windows, переменные `JAVA_HOME` и `ANDROID_HOME`). Ключ и защищённый пароль сохраняются в игнорируемой папке `work/signing/`; подробности резервного копирования — в инструкции релизов.

## Безопасное тестирование

`Pult.Agent.exe --demo --data-dir <папка>` запускает интерфейс и API на localhost:47598 с имитацией системных действий. Громкость, питание и блокировка на ПК не меняются. Может работать одновременно с настоящим агентом.

`Pult.Agent.exe --integration-test --data-dir <папка>` запускает HTTPS только на localhost:47599, проверяет привязку и команды с имитацией ОС и записывает `integration-result.json`. Настоящие команды питания не выполняются.

## Обновления

Версии независимы: `android-v0.1.1` публикует только APK, `agent-v0.1.2` — только Windows-установщик и архив. Каждая часть фильтрует собственные stable-релизы с пагинацией. Приложение и агент сообщают версию протокола отдельно от версии продукта.

Android скачивает APK из собственного репозитория, проверяет пакет, версию и совпадение подписи и открывает системный установщик. При первом обновлении Android может попросить разрешить установку из этого приложения.

Агент предлагает обновление своего компонента, скачивает установщик из GitHub-релиза и проверяет SHA-256 из метаданных GitHub. После подтверждения агент завершается, а установщик обновляет файлы в постоянной папке. По завершении установки можно запустить Пульт. Активный таймер блокирует обновление. Настройки, телефоны и сертификат находятся отдельно в `%LOCALAPPDATA%\Pult` и сохраняются при обновлении и удалении приложения. Выбор автозапуска сохраняется. Обновление без участия пользователя и автоматический откат пока не реализованы.
