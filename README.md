# Пульт

Управление Windows с Android по домашней сети. Без облачного сервера и аккаунта в приложении.

[Скачать APK](https://github.com/cveloy102/pult/releases/download/android-v0.2.0/pult-android-0.2.0.apk) · [Скачать агент для Windows](https://github.com/cveloy102/pult/releases/download/agent-v0.2.0/pult-agent-0.2.0-win-x64-setup.exe) · [Страница приложения](https://cveloy102.github.io/pult/)

Для первого подключения установите обе части. Телефон сканирует QR-код, показанный в окне агента на ПК.

- Выключение и перезагрузка с подтверждением, блокировка экрана.
- Включение ПК с телефона по сети (Wake-on-LAN).
- Один таймер до 24 часов; подтверждение действия, создание и отмена с телефона. На ПК — отсчёт на значке трея, отмена из его меню, история таймеров и окно с отменой за минуту до срабатывания.
- Громкость, системная команда play/pause и выбор устройства вывода Windows с телефона.
- Тёмная и светлая темы, общий дизайн-код у Android и агента Windows.
- Виджет «Питание» и расширенный виджет с громкостью −/+.
- Агент с окном, треем и включаемым автозапуском.
- HTTPS, привязка по QR-коду или с ручной сверкой сертификата, временный код, отзыв доступа.
- Проверка сети в агенте: тип сети и правила брандмауэра Windows, исправление в один клик.
- Раздельные релизы и проверка обновлений Android/Windows.

Минимум: Android 12 (API 31), Windows 10/11 x64. Управление курсором пока не планируется.

## Первый запуск

1. Скачайте APK и агент Windows по ссылкам выше. Для тестирования можно собрать debug APK.
2. Установите агент. По умолчанию он запускается при входе в Windows и находится в `%LOCALAPPDATA%\Programs\Pult`. [Архив Windows](https://github.com/cveloy102/pult/releases/tag/agent-v0.2.0) остаётся доступным для переносного запуска.
3. ПК и телефон должны быть в одной домашней сети. Для входящих подключений Windows нужна частная сеть и разрешение для агента в брандмауэре: TCP 47591 и UDP 47592. Не открывайте эти порты в интернет.
4. На ПК нажмите «Подключить телефон» и отсканируйте QR-код: Android → Настройки → «Сканировать QR-код». Отпечаток и код проверяются автоматически.
5. Без камеры: Настройки → «Найти ПК в сети» или IP-адрес, затем сверьте **полный отпечаток сертификата** и введите одноразовый код с ПК.
6. Добавьте виджет через обычное меню виджетов Android. Его тема следует настройкам приложения.
7. Если телефон не подключается, откройте «Обзор» в агенте: блок «Сеть» покажет тип сети и правила брандмауэра. `Pult.Agent.exe --network-check` записывает тот же результат в `%LOCALAPPDATA%\Pult\network-check.json`.

**Включение по сети.** Пока ПК включён, телефон запоминает его MAC-адрес. Когда ПК недоступен, на главном экране появляется «Включить компьютер». Нужны подключение кабелем и включённое пробуждение по сети в BIOS/UEFI и в свойствах сетевой карты Windows («Wake on Magic Packet»). Из выключенного состояния при включённом «Быстром запуске» Windows некоторые платы не просыпаются.

При выключении приложения Windows могут ожидать сохранения документов: принудительное закрытие не используется. Таймер работает при запущенном агенте. Пропущенный во сне или при остановке агента срок отменяется.

## Сборка

Windows: .NET SDK 10.

```powershell
dotnet build agent/Pult.Agent/Pult.Agent.csproj -c Release
dotnet run --project agent/Pult.Tests/Pult.Tests.csproj
dotnet publish agent/Pult.Agent/Pult.Agent.csproj -c Release -r win-x64 --self-contained true -o artifacts/agent
```

Android: JDK 17+, Android SDK 37.0 и build-tools 36.0.0; Gradle wrapper находится в `android/`.

```powershell
cd android
.\gradlew.bat :app:assembleDebug :app:lintDebug
```

Debug APK: `android/app/build/outputs/apk/debug/app-debug.apk`. Для релизной сборки настройте постоянный ключ подписи; debug-версия не обновится APK с другой подписью.

Локальная подписанная версия: `scripts/build-android-release.ps1` (Windows, переменные `JAVA_HOME` и `ANDROID_HOME`). Ключ и защищённый пароль сохраняются в игнорируемой папке `work/signing/`; подробности резервного копирования — в инструкции релизов.

## Безопасное тестирование

`Pult.Agent.exe --demo --data-dir <папка>` запускает интерфейс и API на localhost:47598 с имитацией системных действий. Громкость, питание и блокировка на ПК не меняются. Может работать одновременно с настоящим агентом.

Android unit-тесты: `.\gradlew.bat :app:testDebugUnitTest`.

`Pult.Agent.exe --integration-test --data-dir <папка>` запускает HTTPS только на localhost:47599, проверяет привязку и команды с имитацией ОС и записывает `integration-result.json`. Настоящие команды питания не выполняются.

## Обновления

Версии независимы: `android-v0.2.0` публикует только APK, `agent-v0.2.0` — только Windows-установщик и архив. Каждая часть фильтрует собственные stable-релизы с пагинацией. Приложение и агент сообщают версию протокола отдельно от версии продукта.

Android скачивает APK из собственного репозитория, проверяет пакет, версию и совпадение подписи и открывает системный установщик. При первом обновлении Android может попросить разрешить установку из этого приложения.

Агент предлагает обновление своего компонента, скачивает установщик из GitHub-релиза и проверяет SHA-256 из метаданных GitHub. После подтверждения агент завершается, а установщик обновляет файлы в постоянной папке. По завершении установки можно запустить Пульт. Активный таймер блокирует обновление. Настройки, телефоны и сертификат находятся отдельно в `%LOCALAPPDATA%\Pult` и сохраняются при обновлении и удалении приложения. Выбор автозапуска сохраняется. Обновление без участия пользователя и автоматический откат пока не реализованы.

[Публикация релизов](docs/releases.md) · [Протокол](docs/protocol.md) · [План продукта](docs/product-plan.md)

Автозапуск Windows использует задачу `Pult Agent (<имя пользователя>)`: вход текущего пользователя, задержка 15 секунд, обычные права, запуск в трей. При ошибке запуска — до трёх повторов с интервалом в минуту. Запись старого способа в `Run` удаляется после успешной регистрации задачи. Результат виден в Планировщике задач, журнал агента — `%LOCALAPPDATA%\Pult\startup.log`.
