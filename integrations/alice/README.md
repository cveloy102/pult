# Алиса → Пульт

Мост для Windows принимает завершённые голосовые запросы рутованной колонки
через Quasar IPC в проверенном SSH-туннеле. Команды выполняет уже установленный
Пульт через HTTPS на localhost. Интернет-портов и нового HTTP-сервера нет.
Работает, пока запущены Windows, Пульт и мост. WoL остаётся отдельной службой колонки.

Примеры после «Алиса»:

| Фраза | Действие |
| --- | --- |
| Выключи ПК / компьютер | Запрос подтверждения |
| Перезагрузи ПК / компьютер | Запрос подтверждения |
| Заблокируй ПК / компьютер | Блокировка |
| Поставь громкость ПК / компьютера на 50 процентов | Громкость 0–100 |
| Сделай ПК / компьютер громче / тише | Шаг +5 / −5 |
| Выключи звук на ПК / компьютере | Громкость 0 |
| Поставь на паузу ПК / компьютер | Системная кнопка play/pause |
| Продолжи воспроизведение на ПК / компьютере | Та же кнопка play/pause |
| Выключи / перезагрузи / заблокируй ПК через 30 минут | Таймер Пульта |
| Поставь таймер выключения ПК / компьютера на один час тридцать минут | Таймер Пульта |
| Отмени таймер ПК / компьютера | Отмена таймера |

Таймеры: 1 секунда–24 часа; блокировка, выключение или перезагрузка.
Существующий таймер не заменяется. Перед выключением, перезагрузкой и созданием
соответствующих таймеров колонка проигрывает запрос подтверждения.
Ответ — «Алиса, подтверди выключение ПК», «…перезагрузку ПК»,
«…таймер выключения ПК» или «…таймер перезагрузки ПК».
Вместо «ПК» можно сказать «компьютера». Простое «да» не выполняет команду.
Любая другая завершённая фраза отменяет ожидание; «Алиса, отмена» отменяет его явно.
Срок — 30 секунд после начала подсказки. Обрыв соединения отменяет ожидание.

Это точный список шаблонов: отрицания, составные команды, произвольные программы,
shell и вызовы от языковой модели не поддерживаются. Громкость и таймеры
принимают цифры и русские числительные до ста. Пауза — переключатель Пульта,
поэтому повторное выполнение продолжает воспроизведение.

## Настройка

Нужны Python 3.10+, OpenSSH, готовый ключ и known_hosts колонки, работающий Пульт.
Получение root и первоначальная настройка SSH не входят в мост.
Исходники можно скопировать в постоянную папку пользователя.

1. В Пульте нажмите «Подключить телефон», сверьте отпечаток сертификата.
2. Выполните `python pair.py --fingerprint <полный-SHA256> --credentials <путь-к-DPAPI-файлу>`.
   Введите временный код. Подключение «Алиса» появится среди устройств Пульта.
3. Создайте локальный JSON-конфиг со строковыми абсолютными путями:

```json
{
  "credentials": "C:/Users/USER/AppData/Local/PultAlice/credentials.dpapi",
  "log": "C:/Users/USER/AppData/Local/PultAlice/bridge.log",
  "ssh_key": "C:/PATH/station_key",
  "known_hosts": "C:/PATH/known_hosts",
  "ssh_port": 2222,
  "ssh_target": "root@STATION_LAN_IP"
}
```

4. Подготовьте голосовые WAV (например, `make-sounds.ps1` с русским SAPI-голосом
   Windows) и загрузите восемь файлов в `/data/opt/pult-alice/` колонки.
   Имена совпадают с ключами в скрипте. В текущем варианте подсказки озвучены
   Microsoft Irina, это не облачный голос Алисы.
5. `python bridge.py --config <конфиг> --check` проверяет доступ без выполнения команд.
6. `pythonw bridge.py --config <конфиг>` запускает мост без окна.
   Также можно запускать `pythonw start.py`, если конфиг лежит рядом как `config.json`.
   Для автозапуска создайте ярлык на `pythonw.exe` с аргументом — полным путём
   к `start.py` — в папке автозагрузки текущего пользователя.

Токен защищён DPAPI для текущего пользователя Windows и остаётся на ПК.
Сертификат проверяется до отправки токена. Доступ отзывается удалением «Алисы»
из списка устройств Пульта. Мост использует стандартную привязку Пульта:
его токен имеет права обычного клиента API; список голосовых действий ограничен
самим мостом. Отдельные серверные роли в текущем протоколе Пульта отсутствуют.
Не копируйте локальные конфиги, ключи и DPAPI-файлы в репозиторий.

Мост не записывает распознанные фразы, только результаты обработки и соединения.
Неопределённый результат API не повторяется автоматически; requestId стабилен
для каждого голосового запроса. Два экземпляра моста блокируются локальным lock-файлом.
Исходники интеграции не меняют установленный агент и Android-приложение.

## Проверка

`python -m unittest discover -s integrations/alice -p test_bridge.py -v`
из корня репозитория. Проверяются запрет произвольных команд, оба варианта имени ПК,
границы таймеров, подтверждения и их истечение, частичные/старые запросы, повторы,
обрыв подсказки и повреждённые сообщения. Системные действия заменены имитацией.
Тесты не доказывают живое распознавание на всех моделях и прошивках колонок.
