# Протокол Пульта, версия 1

HTTPS TCP 47591, discovery UDP 47592. Только локальные адреса; без браузерных Origin/CORS. UTF-8 JSON camelCase. До 4 KiB в запросе. Ответы не кэшируются.

## Привязка

1. Пользователь создаёт на ПК одноразовый шестизначный код на 2 минуты.
2. Android получает `/api/info` без учётных данных и показывает SHA-256 сертификата.
3. Пользователь сверяет полный отпечаток с окном агента.
4. Android закрепляет сертификат и отправляет `POST /api/pair`: `{"code":"123456","name":"POCO F7"}`.
5. Агент возвращает `token`, `phoneId`, `agent`. Код немедленно инвалидируется. Максимум 5 попыток с адреса / 20 суммарно за 2 минуты.

Токен: 256 случайных бит, 64 hex-символа. На ПК хранится SHA-256 токена; на Android токен и привязка зашифрованы ключом Android Keystore. Приватный ключ HTTPS защищён Windows DPAPI текущего пользователя.

## Запросы

`GET /api/info`: `name`, `version`, `protocol`, `capabilities`, `fingerprint`.

`GET /api/status`, заголовок `Authorization: Bearer TOKEN`: `name`, `version`, `protocol`, `capabilities`, `timer`, `audio`, `error`, `outputs`.

`timer`: null или `{id,action,dueAt}`. `dueAt` — дата UTC в ISO 8601. `audio`: null или `{volume,muted}`; отсутствие устройства не делает питание недоступным.

Возможность `audioOutput` добавлена без смены протокола: `outputs` — список активных выходов `{id,name,selected}`, только устройства воспроизведения. Android показывает выбор только при наличии этой возможности; со старым агентом остальные команды работают. `id` — непрозрачный идентификатор Windows, а не индекс или название. Системный выход console/multimedia переключается, отдельный выход communications сохраняется. При частичной ошибке агент пытается восстановить прежние выходы.

`POST /api/command`, тот же заголовок, `Content-Type: application/json`:

```json
{"requestId":"UUID","action":"volume","value":38}
```

| action | Параметры |
|---|---|
| shutdown, restart, lock, playPause | Без дополнительных параметров |
| volume | value 0..100 |
| volumeStep | value -5 или 5 |
| audioOutput | deviceId из текущего outputs, до 512 символов |
| timer | timerAction shutdown/restart/lock, durationSeconds 1..86400, replace false/true |
| cancelTimer | Без дополнительных параметров |

Повторное использование UUID с тем же запросом не исполняет команду ещё раз. Изменённое содержимое с тем же UUID — 409. Незавершённая попытка после ошибки/перезапуска — 409: результат неизвестен, автоматического повторения нет. Агент хранит последние 1000 подтверждений; клиент не должен автоматически повторять старые запросы за пределами этого окна.

Новый таймер при активном таймере — 409, пока пользователь явно не согласится на `replace:true`. Отмена подтверждается только ответом агента. Действия ОС сериализованы с отменой и выполнением таймера.

Ответ успешной команды: `{accepted:true,duplicate:false,message:"…"}`. Ошибка: `{error:"…"}` и HTTP 400/401/409/429/500. Повторение после неизвестного сетевого результата — только тем же UUID; UI не делает этого автоматически.

## Поиск

Запрос UDP: `PULT_DISCOVER_V1:UUID` на broadcast порт 47592. Ответ JSON: `{requestId,name,port,fingerprint,protocol}`. Android использует адрес отправителя и проверяет nonce. Discovery не доказывает идентичность: нужна сверка отпечатка на ПК.

## Совместимость

Android и Windows имеют независимые версии продукта. Совпадение версии протокола и поддерживаемых возможностей определяет совместимость. Изменения UI не меняют протокол. Несовместимая версия протокола блокирует привязку и команды.
