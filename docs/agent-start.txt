Пульт для Windows 10/11 x64

1. Запустите pult-agent-…-win-x64-setup.exe: установка в папку текущего пользователя.
   Для переносного запуска распакуйте весь архив в постоянную папку.
2. Запустите Пульт. Агент работает в трее; окно можно закрыть.
3. Разрешите приложению входящие подключения только в частной домашней сети.
4. Нажмите «Подключить телефон» и следуйте инструкции на экране.

HTTPS: TCP 47591. Автоматический поиск: UDP 47592.
Проброс портов на роутере для работы по домашнему Wi-Fi не нужен.

Обновление: нажмите «Обновления» в агенте. После подтверждения он скачает
и проверит установщик, затем завершится. Завершите установку и запустите Пульт.
Можно также скачать установщик вручную и предварительно завершить агент через трей.
Во время активного таймера сначала дождитесь его выполнения или отмените его.
Настройки, телефоны и сертификат хранятся отдельно в %LOCALAPPDATA%\Pult.
Установщик сохраняет выбор автозапуска и использует постоянную папку программы.

При создании таймера появляется окно обратного отсчёта. Отменить его можно
с телефона, из этого окна, главного окна и трея. Закрытие окна не отменяет таймер.
Таймер исполняется только пока агент запущен. Если срок пропущен при сне ПК
или остановке агента, таймер отменяется, чтобы ПК не выключился внезапно.
Для выключения не используется принудительное закрытие приложений: Windows
может ожидать сохранения открытых документов.
